# README showcase provenance

The desktop-first hero in `marketdesk-readme-hero.svg`, its editable HTML source, and the narrow composition `marketdesk-readme-hero-mobile.svg` were generated through OpenDesign, not recreated manually. OpenDesign project: `marketdesk-readme-showcase` (MarketDesk README Showcase). Original desktop generation run: `b9c7cc98-2dfa-4694-866b-b586bc29d161` (request ID `01K6PK5J6VBG1MZM6MZ0TT69AQ`); narrow-layout refinement run: `719e27a2-edb2-4220-b4f9-2221d204acb0` (request ID `01K6PK8BJXCY5QAM8R48Z6RPND`); desktop readability and dashboard refinement run: `e87c4fdb-6d14-42bb-983c-468e81be459a` (request ID `6c839bea-045a-45d1-a896-ff71101347fe`). The current generated source is [`marketdesk-readme-source.html`](marketdesk-readme-source.html); its inline SVG is also the standalone desktop hero. Root README selects the wide desktop composition by default; the stacked mobile companion is selected only at viewport widths up to 767 CSS pixels.

The illustrations were commissioned from verified current product facts in `docs/spec/PRODUCT.md`, supplied directly in the prompt because OpenDesign runs in an isolated workspace without repository access. The project mark geometry and colors were passed inline from `public/marketdesk-mark.svg`. The refined desktop SVG is a 1200 × 650 landscape dashboard with sidebar navigation and a multi-column seller workspace; primary interface labels use 14–18px source type and supporting labels 12–13px. The narrow SVG retains its generated 360 × 930 stacked composition. Artwork is conceptual, not a product screenshot; all displayed sample workspace content is synthetic. It marks OLX as the only validated integration, names other channels as roadmap, and depicts Hermes as a proposal for human review. No runtime brand assets or hosted `quokkify/.github` screenshots were changed.

Both SVGs use inline vector shapes and system/serif font fallbacks only; they load no external fonts, images, or scripts. Each includes an accessible title and description. The desktop composition is 1200 × 650; the narrow composition canvas is 360 × 930 with a stacked layout. The `picture` source breakpoint is 767px: 390 and 600px select the narrow asset; 768, 1024, 1280 and 1440px select the desktop asset. Local rendering and actual GitHub-hosted screenshots are tracked separately; do not infer GitHub sanitizer/render behavior from this local source inspection.
