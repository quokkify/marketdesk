# README showcase provenance

The desktop hero in `marketdesk-readme-hero.svg`, its editable HTML source, and the narrow composition `marketdesk-readme-hero-mobile.svg` were generated through OpenDesign, not recreated manually. OpenDesign project: `marketdesk-readme-showcase` (MarketDesk README Showcase). Desktop generation run: `b9c7cc98-2dfa-4694-866b-b586bc29d161` (request ID `01K6PK5J6VBG1MZM6MZ0TT69AQ`); narrow-layout refinement run: `719e27a2-edb2-4220-b4f9-2221d204acb0` (request ID `01K6PK8BJXCY5QAM8R48Z6RPND`). The generator's project and Studio are available for the current daemon session: http://127.0.0.1:7456/projects/marketdesk-readme-showcase/conversations/9d7365f5-cf4c-4915-9a1b-a75631cd2030 . The editable generated source is [`marketdesk-readme-source.html`](marketdesk-readme-source.html); its inline SVG is also the standalone desktop hero. The README intentionally uses the readable narrow composition at every width, capped at 560 CSS pixels, because the denser desktop artwork's labels become too small when GitHub scales it to the available content width. The wide desktop concept remains available as a separately linked artifact.

The illustration was commissioned from verified current product facts in `docs/spec/PRODUCT.md`, supplied directly in the prompt because OpenDesign runs in an isolated workspace without repository access. The project mark geometry and colors were passed inline from `public/marketdesk-mark.svg`. The artwork is a concept, not a product screenshot; all displayed sample workspace content is synthetic. It marks OLX as the only validated integration, names other channels as roadmap, and depicts Hermes as a proposal for human review. No runtime brand assets or hosted `quokkify/.github` screenshots were changed.

Both SVGs use inline vector shapes and system/serif font fallbacks only; they load no external fonts, images, or scripts. Each includes an accessible title and description. The desktop composition is 1200 × 660; the mobile version is 360 × 930 with a stacked layout and legible 13px+ UI copy at intrinsic width. Captured review screenshots used Playwright's installed Chromium Headless Shell at 1200px and 360px viewport widths; the narrow-specific asset was also rendered at its intrinsic 360px width.
